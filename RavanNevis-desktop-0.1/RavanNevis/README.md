# روان‌نویس — نسخه‌ی ویندوز (۰٫۱)

برنامه‌ی دسکتاپ برای ویندوز ۱۰ و بالاتر (۶۴ بیتی).

## ساخت فایل نصب (دو راه)

### راه اول: روی همین کامپیوتر
1. Node.js نسخه‌ی LTS را از https://nodejs.org نصب کنید.
2. روی فایل `build.bat` دوبار کلیک کنید و صبر کنید (بار اول چند دقیقه طول می‌کشد و اینترنت لازم است).
3. فایل نصب در پوشه‌ی `dist` ساخته می‌شود (مثلاً `RavanNevis Setup 0.1.0.exe`). آن را اجرا کنید.

### راه دوم: ساخت خودکار روی GitHub (بدون نصب چیزی)
1. در github.com یک مخزن (Repository) خصوصی بسازید و همه‌ی فایل‌های این پوشه را در آن بارگذاری کنید.
2. به تب Actions بروید، گردش‌کار `build-windows` را اجرا کنید (Run workflow).
3. پس از پایان، فایل نصب را از بخش Artifacts دانلود کنید.

## اجرای آزمایشی بدون ساخت فایل نصب
بعد از `npm install` دستور `npm start` برنامه را باز می‌کند.

## هشدار ویندوز
چون فایل نصب امضای دیجیتال (Code Signing) ندارد، ویندوز ممکن است پیام SmartScreen نشان دهد. «More info» و بعد «Run anyway» را بزنید. برای حذف این پیام باید گواهی امضا تهیه شود.

## چه چیزی واقعی است و چه چیزی هنوز نه (نسخه‌ی ۰٫۱)
واقعی:
- نصب و اجرا روی ویندوز، ذخیره‌ی پیش‌نویس‌ها، ایده‌ها و تنظیمات روی همین کامپیوتر
- «ورود امن» به سایت مجله: پنجره‌ی خود سایت باز می‌شود و شما وارد می‌شوید؛ رمز شما به برنامه داده نمی‌شود
- «خواندن ساختار مجله»: صفحه‌های راهنما و ارسال سایت را با نشست شما می‌خواند و حداکثر کلمات و سبک ارجاع را (اگر پیدا کند) نشان می‌دهد
- خواندن فایل Word (docx) و متن ساده در افزودن مقاله

هنوز شبیه‌سازی است:
- ارسال واقعی مقاله به سایت مجله (چیزی ارسال نمی‌شود)
- اتصال ORCID، سیویلیکا و نور، و تشخیص خودکار جایگاه علمی
- همگام‌سازی مرکز داده و رتبه‌ی الف و ب
- ثبت خودکار در رزومه
- هوش مصنوعی (فقط تنظیمات)
- ثبت‌نام و ورود فقط یک حساب محلی آزمایشی است
